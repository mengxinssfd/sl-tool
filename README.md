# 单机游戏存档管理工具

一款基于 Electron + React + TypeScript 开发的单机游戏存档管理工具，帮助玩家轻松管理游戏存档，支持快速存档、读档、备份和恢复功能。

## 功能特性

### 🎮 游戏管理
- 添加/编辑/删除游戏配置
- 设置游戏存档路径和备份路径
- 设置游戏执行文件，一键启动游戏
- 备份路径更改时自动迁移所有备份文件

### 💾 存档管理
- 创建新存档
- 快速存档/读档
- 存档复制功能
- 存档备份和恢复

### 📁 文件操作
- 一键打开存档文件夹
- 一键打开备份文件夹
- 配置导入（增量导入）/导出

### 🌐 国际化
- 支持中文/英文切换
- 自动检测系统语言

## 技术栈

- **框架**: Electron 28 + React 18
- **语言**: TypeScript
- **样式**: TailwindCSS 3
- **状态管理**: Zustand
- **构建工具**: Vite

## 使用说明

### 1. 添加游戏

1. 点击左侧游戏列表的「添加游戏」按钮
2. 填写游戏名称
3. 设置存档路径（游戏存档所在目录）
4. 设置备份路径（备份文件存储目录）
5. 可选：设置游戏执行文件路径，以便一键启动游戏

### 2. 管理存档（备份）

- **新增存档**: 点击存档详情页的「新增存档」按钮
- **快速更新**: 点击「更新」按钮复制原存档到当前备份
- **快速读档**: 点击「还原」按钮恢复备份到存档
- **编辑**: 点击存档项的编辑图标修改备份名称和备注
- **删除存档**: 点击存档项的删除图标删除备份
- **复制存档**: 点击存档项的「复制」按钮复制备份

### 3. 启动游戏

如果设置了游戏执行文件路径，点击存档详情页的绿色播放按钮即可启动游戏。

